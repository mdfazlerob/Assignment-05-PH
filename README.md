About project:
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Project Name:-
DevStack

Description:-
DevStack হলো ডেভলপারদের জন্য তৈরি একটি ইন্টারঅ্যাক্টিভ প্ল্যাটফর্ম, যার মাধ্যমে ফ্রন্টএন্ড, ব্যাকএন্ড, ডেটাবেস এবং টুলসের বিভিন্ন অপশন এক্সপ্লোর ও তুলনা করে নিজের প্রজেক্টের জন্য নিখুঁত টেকনোলজি স্ট্যাক তৈরি করা যায়।

Technologies Used:-
Frontend Frameworks & Libraries: React, Vue.js, Svelte, Next.js

Backend & Runtimes: Node.js, Java

Databases & Caching: PostgreSQL, Redis

Languages & Styling: JavaScript, TypeScript, Tailwind CSS

DevOps & Containerization: Docker

Key Features:-

1.Interactive Tech Stack Builder: ব্যবহারকারীরা বিভিন্ন ক্যাটাগরির প্রযুক্তি ব্রাউজ করে নির্দিষ্ট টেকনোলজি নির্বাচন করতে পারেন এবং সাইডবারে ("Your Stack" প্যানেল) লাইভ কাস্টমাইজড স্ট্যাক তৈরি ও ট্র্যাক করতে পারেন।

2.Category & Metadata Tagging: প্রতিটি টেকনোলজি কার্ডে ক্যাটাগরি ট্যাগ (যেমন: Frontend, Backend, Database), ডিফিকাল্টি লেভেল (Beginner-Friendly, Intermediate), রেটিং এবং স্পেশাল ব্যাজ (Popular, Fast, Essential) স্পষ্টভাবে প্রদর্শিত হয়।

3.Side-by-Side Comparison: নতুন প্রজেক্টের সঠিক সিদ্ধান্ত নেওয়ার সুবিধার্থে বিভিন্ন ফ্রেমওয়ার্ক ও টুলের ফিচারের মধ্যে পাশাপাশি তুলনা করার সুযোগ রয়েছে।



Answer the questions:
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------

1.What is JSX, and why is it used in React?
  => JSX lets us write HTML-like code inside JavaScript. It makes React code easier to read and build UI.
  
2.What is the difference between props and state?
  => Props are data passed from a parent to a child. State is data managed inside a component that can change.
  
3.What does useState do, and where did you use it?
  => useState lets us store and update data in a component. I used it to manage things like the stack/list data and user interactions.
  
4.What does useEffect do, and why did you need it for JSON data?
  => useEffect runs code when something happens, like when the component loads. I used it to fetch and load the JSON data when the page started.

5.Why does every .map() item need a unique key?
  => The key helps React identify each item and update the list efficiently when something changes.

6.What is conditional rendering?
  => Conditional rendering means showing different UI based on a condition. For example, I showed an empty stack message when there were no items.

7.How do you pass data between parent and child components?
  => A parent passes data to a child using props. To send something back, the parent passes a function as a prop, and the child calls that function.
